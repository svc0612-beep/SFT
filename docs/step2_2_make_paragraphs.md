# 전처리 2-2단계: 줄 → 문단으로 이어붙이기

- 코드: `scripts/step2_2_make_paragraphs.py`
- 실행: `python scripts\step2_2_make_paragraphs.py` (C:\STF 에서)
- 입력: `data/processed/step2_1_lines.jsonl` (2-1 결과)
- 결과:
  - `data/processed/step2_2_paras.jsonl` — 페이지마다 제목, 대제목, 문단 목록
  - `data/processed/step2_2_view.txt` — 눈으로 확인용 (소제목은 `## `로 표시)

## 한 줄 요약

줄 단위로 잘려 있는 텍스트를 사람이 읽는 **문단**으로 다시 붙인다.

```
전:  보통 모바일 데이터 네
     트워크보다 빠릅니다.
후:  보통 모바일 데이터 네트워크보다 빠릅니다.
```

## 1. 문단 나누기

아래 중 하나라도 해당하면 **새 문단**을 시작한다.

| 기준 | 예시 |
|---|---|
| 윗줄과 간격이 벌어짐 (y 차이 > 13.5) | 같은 문단 안 줄 간격 ≈ 10.8, 문단 사이 ≥ 15 |
| 소제목 (굵고 본문보다 큰 글씨) | "진단", "핫스팟" (크기 14) |
| 소제목 바로 다음 줄 | 소제목 아래 본문 시작 |
| 번호·글머리표로 시작 | "1.", "•", "◦" |
| 참고·경고·주의로 시작 | "참고:", "경고:", "주의:" |
| 단이 바뀜 | 왼쪽 단 → 오른쪽 단 |

## 2. 같은 문단 안에서 줄 이어붙이기 (띄어쓰기 복원)

2-1에서 일부러 남겨둔 **줄 끝 공백**을 단서로 쓴다.

| 윗줄 끝 상태 | 처리 | 예시 |
|---|---|---|
| 공백 있음 | 띄워서 이음 | "소프트웨어 " + "및 지도" → "소프트웨어 및 지도" |
| 공백 없음 + `.` `:` `!` `?`로 끝남 | 띄워서 이음 (문장 끝) | "…81." + "이 표시등" → "…81. 이 표시등" |
| 공백 없음 | 붙여서 이음 (단어 중간에서 끊김) | "네" + "트워크" → "네트워크" |

## 2-2에서 안 하는 것

- 페이지 참조 "(라이트 페이지의 70)" 삭제 → 2-3
- 표 잔해 ("36-48", "✓") 삭제 → 2-3
- `을(를)` 같은 조사 묶음 정리 → 2-3
- 같은 제목 페이지끼리 섹션으로 묶기, 페이지 사이에 끊긴 문장 잇기 → 2-4
