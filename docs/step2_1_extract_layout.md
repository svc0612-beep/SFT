## 이제 추가사전학습

왜?
사전학습: 아무것도 모르는 빈 모델한테 대량의 텍스트를 처음부터 읽히는 거야. koGPT2는 SKT가 이미 한국어 위키, 뉴스 같은 대량 데이터로 이걸 해놨어.
추가 사전학습: 이미 사전학습된 koGPT2를 가져와서 테슬라 매뉴얼 본문을 더 읽히는 거야. 한국어는 이미 아니까, 테슬라 용어랑 문체만 추가로 익히는 거지.
- clean_corpus.txt를 256토큰씩 잘라서 koGPT2한테 "다음 단어 맞히기"를 반복시켜. 이렇게 하면 테슬라 용어랑 매뉴얼 문체에 익숙해져,
